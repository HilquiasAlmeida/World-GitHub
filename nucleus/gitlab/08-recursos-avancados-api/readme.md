# ⚡ 8. Recursos Avançados, API REST e Automações

Este módulo consolida as ferramentas de integração avançada do GitLab para o ecossistema **World GitHub**. Ele capacita equipes de engenharia a automatizar fluxos externos, integrar sistemas legados via API e publicar portais estáticos de documentação.

---

## 📑 Estrutura de Documentos do Módulo
* [Automações via API REST](./api-rest-automations.md) — Exemplos práticos em cURL e scripts para gerenciar recursos programmaticamente.
* [Integração via Webhooks](./webhooks-integration.md) — Disparo de eventos em tempo real para sistemas externos, chatbots e microsserviços.
* [GitLab Pages](./gitlab-pages.md) — Hospedagem nativa de sites estáticos e documentações corporativas direto do repositório.

---

## 🎯 Objetivo Arquitetural
Garantir que o GitLab funcione não apenas como repositório de código, mas como uma plataforma programável capaz de se comunicar com qualquer ferramenta do ecossistema corporativo sem intervenção humana manual.
