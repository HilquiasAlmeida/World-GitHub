# 💻 Web IDE: Desenvolvimento Ágil Direto no Navegador

  O **Web IDE** do GitLab é um ambiente completo de desenvolvimento baseado em VS Code executado inteiramente dentro do navegador, permitindo criar, editar e enviar alterações de código sem precisar clonar o repositório localmente.

---

## 1. Como Acessar a Web IDE
  1. Navegue até a página principal do seu projeto no GitLab.
  2. Pressione a tecla **`.` (ponto)** no seu teclado ou clique no botão **Edit** > **Web IDE** no canto superior direito da listagem de arquivos.
  3. O ambiente carregará instantaneamente com a interface idêntica ao Visual Studio Code.

---

## 2. Fluxo de Edição, Commit e Merge Request na Web IDE
  1. **Edição:**
       Altere os arquivos desejados no painel esquerdo.
       O controle de alterações (*Source Control*) indicará quais arquivos foram modificados.
     
  2. **Commit:**
     Clique no ícone de controle de versão (terceiro ícone na barra lateral esquerda),
       digite a mensagem do commit e clique em **Commit & Stage Changes**.
  
  3. **Criação de Branch e MR:**
       O sistema perguntará se você deseja criar uma nova branch para as alterações e abrirá automaticamente
       a opção para criar um **Merge Request (MR)** direto da interface visual.
