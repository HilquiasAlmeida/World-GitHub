# 🌐 11: Portal Web e Interface Visual do GitLab

Este módulo consolida o guia de uso e administração do **Portal Web** do GitLab para o ecossistema **World GitHub**. Ele é voltado tanto para engenheiros que preferem a interface gráfica quanto para product owners, gestores e usuários operacionais que gerenciam o ciclo de vida sem interagir com linhas de comando.

---

## 📑 Estrutura de Documentos do Módulo
* [Web IDE e Edição no Navegador](./web-ide-editing.md) — Como utilizar o ambiente de desenvolvimento baseado em VS Code integrado diretamente no navegador.
* [Configurações e Governança de Projetos (Settings)](./project-settings-governance.md) — Gestão de membros, permissões, branches protegidas e ativação de recursos visuais.
* [Navegação de Dashboards e Quadros Visuais](./navigation-dashboards.md) — Gestão de Issue Boards, visualização de pipelines, merge requests e painéis gerenciais.

---

## 🎯 Objetivo Arquitetural
Garantir que a experiência visual no navegador seja intuitiva, padronizada e alinhada com as exigências de governança Enterprise do World GitHub.
