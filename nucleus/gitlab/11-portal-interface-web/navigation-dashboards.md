# 📊 Navegação de Dashboards e Quadros Visuais (Issue Boards)

  Os painéis visuais do GitLab permitem monitorar o progresso das entregas, o status das pipelines de CI/CD e o fluxo de trabalho das equipes em tempo real.

---

## 1. Utilizando os Quadros Kanban (Issue Boards)
  1. No menu lateral esquerdo do projeto, acesse **Plan** > **Issue boards**.
  2. O quadro organiza visualmente as issues por colunas com base nas labels de workflow (ex: *Backlog*, *Ready*, *In Progress*, *In Review*, *Done*).
  3. **Arrastar e Soltar (Drag-and-Drop):** Você pode mover uma issue de uma coluna para outra com o mouse; o GitLab atualizará a etiqueta de status automaticamente.

---

## 2. Monitoramento Visual de Pipelines (CI/CD Dashboard)
  1. Acesse **Build** > **Pipelines** no menu lateral.
  2. Visualize o status gráfico de cada estágio (*Build*, *Test*, *Security*, *Deploy*).
  3. Clique em qualquer job com falha para abrir o console de log em tempo real diretamente no navegador,
     facilitando o diagnóstico de erros por operadores e analistas de suporte.
