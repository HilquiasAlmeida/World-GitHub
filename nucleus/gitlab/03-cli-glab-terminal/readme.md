# 📊 03. Gerenciamento de Projetos Ágil no GitLab: Do Portfólio à Execução

Este diretório estabelece o padrão corporativo para o gerenciamento ágil de projetos dentro do GitLab, unificando o planejamento estratégico com o ciclo de entrega de software em uma única plataforma (*Single Source of Truth*).

---

## 1. A Filosofia de Gestão Integrada
Gerenciar projetos no GitLab significa que **o planejamento não é dissociado do código**. Enquanto em ecossistemas fragmentados a issue fica no Jira e o código no GitHub, no GitLab a issue nasce, evolui com o desenvolvimento, é tratada no Merge Request e encerra automaticamente quando o deploy atinge a produção.

* **Benefícios de Escala**: Visibilidade em tempo real do progresso de engenharia, eliminação de status reports manuais e rastreabilidade ponta a ponta para auditorias de compliance.
