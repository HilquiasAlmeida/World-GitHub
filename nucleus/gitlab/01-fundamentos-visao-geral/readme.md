# 🌐 01. Fundamentos e Visão Geral do GitLab

Este diretório centraliza a base conceitual sobre o ecossistema do GitLab dentro da arquitetura do projeto.

## O que é o GitLab?
O **GitLab** é uma plataforma de desenvolvimento colaborativo baseada em Git e concebida como uma **única aplicação (Single Application)** para todo o ciclo de vida de DevOps (**DevSecOps**). 

Diferente de outras ferramentas que exigem integrações complexas de terceiros para testes, segurança e gerenciamento, o GitLab integra nativamente:
* **Controle de Versão**: Repositórios Git de alta performance.
* **Planejamento Ágil**: Rastreamento de issues, quadros Kanban (Issue Boards), Milestones e Epics.
* **CI/CD Nativo**: Servidor de integração e entrega contínua com runners escaláveis.
* **DevSecOps**: Varredura automatizada de segurança de código (SAST, Secret Detection, Dependency Scanning).
* **Entrega e Hospedagem**: Container Registry, Package Registry e GitLab Pages para sites estáticos.

## Objetivo deste Módulo
Estabelecer o entendimento macro da plataforma para alinhar a equipe quanto às capacidades nativas que substituem ferramentas fragmentadas de mercado.
